# Contributing

Use [Adagio Community discussions](https://github.com/cymis/adagio-community/discussions) for public questions, workflow feedback, and feature ideas.

Small documentation and skill improvements may be proposed through a pull request. Keep every contribution public-safe: do not include credentials, customer data, protected health information, private source code, private URLs, or biological datasets.

Changes to authentication, permissions, write behavior, app registration, or data handling require an Adagio security review and release qualification. Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
